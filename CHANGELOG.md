# Changelog

## 1.1.0 — Fabric 26.3

- Added Smart Hotbar to the F7 menu with its own on/off switch.
- Assign an item or category to each hotbar slot using a visual picker with icons, name search, and a clear-slot action.
- Smart Hotbar prefers the assigned slot when you pick up items or Shift-click them from a chest. Overflow uses normal inventory placement, and occupied slots keep their contents.
- Preferences are saved per player. In multiplayer, install this version on both the client and the server.
